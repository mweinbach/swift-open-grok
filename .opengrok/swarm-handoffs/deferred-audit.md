Reachability labels:

- VISIBLE-INERT: user-visible command, setting, schema, or documentation exists without a live backing.
- ACCEPTED-REFUSED: parser accepts the input and the live composition rejects it explicitly.
- LIVE-PARTIAL: a real live seam exists, but cited Rust behavior remains missing.
- IMPLEMENTED-UNWIRED: substantive Swift library code exists but no production live-seam consumer exists.
- ABSENT: no Swift implementation or live route exists.
- EVIDENCE-ONLY: code exists, but platform or integration proof is still missing.

Risk labels:

- Critical: misleading or unsafe reachable behavior, state corruption risk, or credential/security boundary.
- High: major live parity failure or externally visible capability gap.
- Medium: bounded feature/UX gap with a clear fallback.
- Low: cleanup, evidence, or polish with limited runtime impact.
